# Host-side dependencies. Five packages, and each one is here for a reason:
#
#   pyserial   the only way to the board. Nothing else in this tree talks to a
#              COM port.
#   pyyaml     test plans are YAML because a process engineer has to be able to
#              read and review one without reading Python.
#   mcp        the Model Context Protocol server in coaxial_mcp/.
#   anyio      what mcp's low-level server runs on; pinned here because
#              coaxial_mcp/server.py imports it directly rather than through mcp.
#   rich       the live views' console renderer - panels, columns and the
#              flicker-free Live repaint. Replaced a hand-rolled ANSI layout
#              that measured escape codes wrong once per restyle; pure
#              Python, no compiled wheels, so the bench PC constraint holds.
#
#   numpy      the least squares in sysid.py and loop.py's runs. It arrived
#              transitively with pandas and the suites imported it directly -
#              a dependency that is real is a dependency that is written.
#   pandas     notebooks. `daq.frame()` gives a DataFrame with a time index
#   matplotlib and a column per channel, pins included, and `daq.plot()` draws
#              it. BOTH ARE IMPORTED WHERE THEY ARE CALLED and refuse with the
#              install line when absent, so the library itself still runs on a
#              bench that has neither - `columns()` is a dict of plain lists,
#              which is what DataFrame takes anyway.
#
# Deliberately absent: reportlab, requests, the ollama client. The PDF writer
# is 172 lines of PDF 1.4 and the Ollama client is urllib. A bench PC at a
# contract manufacturer keeps working through the next OS image in proportion
# to how little it needs installed - which is why the two above are optional at
# the call site even though they are pinned here.
pyserial>=3.5
numpy>=1.24
PyYAML>=6.0
mcp>=1.2,<2      # 2.x removed the low-level Server decorator API this uses
anyio>=4.0
rich>=13.0
pandas>=2.0
matplotlib>=3.7

# Only for examples/pytest_production_line.py. Nothing else in tests/ needs it:
# the conformance, MCP and runner suites are plain scripts with their own
# reporters, so they run on a machine with nothing but the four above.
pytest>=8.0
