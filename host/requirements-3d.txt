#   huggingface-hub  local weight cache management for image-to-3D model containers (the Hunyuan3D-2
#                    CUDA 12.4 runtime itself stays isolated inside Docker via host/requirements-linux.txt
#                    so host/requirements-gpu.txt keeps its CUDA 13.0 stack untouched).
